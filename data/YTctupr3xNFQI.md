# 🔰 Don't learn XML/XHTML (but know what they are)

Introduces what XML looks like and where it still appears, such as SVG images, MathML and Microsoft Word documents, and advises using HTML5 instead of XHTML. Recommends that beginners only recognize XML and spend their study time on JSON and YAML.
