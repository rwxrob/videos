# Honestly, I Used VSCode for Two Full Years, Then Ran Back to Vim

From 2020. I may have changed my mind on some of this.

Rob describes using VS Code for about two years (around 2018) for web development while keeping Vim only for server administration. He explains why VS Code impressed him at first with its speed from canvas GPU acceleration, then how it grew slow and bloated, and how slow startup on servers pushed him back to Vim and a rework of his vimrc.
