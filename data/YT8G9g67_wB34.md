# 🚀 AI Makes Terminal/CLI Skills Essential

Argues that because large language models work entirely with text, terminal and command-line skills have become essential for working with AI. Covers using tmux with multiple Claude sessions and git worktrees, reading commands that AI runs, and why Markdown files like skills.md and agents.md are central to AI workflows.

Everything about development and operations using AI is based on text and command line interaction with the terminal. AI moves at Terminal Velocity and so should you if you want to keep up. (Yes, vim is still very relevant, but tmux is even more relevant.) This is particularly true for SysDE, SRE, and Platform engineering work that all happens through commands that claude and agents are allowed to run (ssh, terraform, ansible, etc.)
